MiMoneda-Prototipo
Aplicación Android en desarrollo para apoyar la gestión de las finanzas personales. El prototipo contempla el registro y consulta de ingresos y gastos, así como una pantalla principal con información resumida y una sección de ayuda.
Estado del proyecto
Proyecto académico en fase de prototipado. La estructura inicial de Android está creada y las pantallas y funcionalidades se irán incorporando progresivamente.
Objetivo
Diseñar una aplicación sencilla que permita organizar los movimientos económicos personales y consultar de forma clara el balance disponible.
Pantallas previstas
- Inicio de sesión.
- Registro de usuario.
- Pantalla principal con balance, accesos para añadir ingresos y gastos, movimientos recientes y ayuda.
- Formularios para registrar ingresos y gastos, con validación de los datos introducidos.
- Confirmación del registro.
  Tecnologías
- Android Studio.
- Java.
- XML para las interfaces.
- Gradle para la configuración y compilación.
  Requisitos
- Android Studio con el Android SDK.
- Un emulador Android o un dispositivo Android para ejecutar la aplicación.
  Ejecución
1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en Android Studio.
3. Espera a que termine la sincronización de Gradle.
4. Selecciona un emulador o conecta un dispositivo Android.
5. Ejecuta la configuración app.
